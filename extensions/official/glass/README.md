# 毛玻璃

一个让窗口变透明的主题，颜色用暖灰。装上以后，在 **设置 → 外观 → 配色主题** 里选「毛玻璃」，下面会出现调整项。换别的主题窗口就不透明了，调过的数值还留着。

## 两种玩法

- **透桌面**：用系统材质，能看到窗口后面的内容。需要 Windows 11 22H2 或 macOS。模糊和亮度由系统决定；窗口失去焦点时 Windows 会变成实色。
- **透壁纸**：透外观设置里选的壁纸，所有选项都能调，但看不到窗口后面的桌面。

## 能调什么

- 预设：通透、均衡、磨砂
- 整体透出、模糊、背景饱和度、背景亮度、噪点、底色
- 侧栏、正文区、右侧面板、输入框和卡片分别透多少，代码块透出，菜单不透明度
- 亮边、卡片圆角
- 自动保证可读、弱字提亮、文字投影
- 什么时候变回实色：失去焦点、用电池、系统减少透明度

设置窗口本身保持不透明，方便调整。

## 已知问题

- 透桌面时背后很亮（比如白底文档）字可能看不清，因为读不到桌面的亮度。把透出调小一些。
- 视频壁纸读不到亮度，「自动保证可读」不起作用。
- Linux 和 Windows 10 只能透壁纸。
