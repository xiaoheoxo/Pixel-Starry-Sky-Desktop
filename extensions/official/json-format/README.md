# JSON 排版

把选中的 JSON 排成两个空格缩进；没有选中时排版整个文件。改动可以撤销。

## 装上以后

- **命令**：命令面板和编辑器右键里的「排版 JSON」，默认快捷键 `Ctrl+Alt+J`（macOS 是 `⌘⌥J`），和别的快捷键冲突时不生效，详情页会写明。
- **权限**：读当前文件（`editor.read`）、改当前文件（`editor.write`）。第一次运行时会问你；不联网，不存任何东西。

## 已知问题

- 只认严格的 JSON，带注释或末尾逗号的（JSONC）会提示解析失败，不会改动文件。
- 超过 1 MB 的文件不能排版整个文件。
- 超出双精度范围的数字会被四舍五入，排版前请确认。
