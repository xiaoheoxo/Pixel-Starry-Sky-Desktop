# 飞书 连接器

让 AI 用飞书应用的身份读写文档、多维表格、日历和消息。

## 怎么用

1. 在[飞书开放平台](https://open.feishu.cn/)建一个企业自建应用，开通需要的权限并发布。
2. 在 设置 › 扩展 › 发现 点「连接」，填 App ID 和 App Secret。
3. 新开一个对话就能用。

## 要知道的

- 它会在你的电脑上运行飞书官方的程序：`npx -y @larksuiteoapi/lark-mcp@0.5.1 mcp`，需要 Node.js 20 以上。第一次启动要下载，可能比较慢；连不上时在「连接器」面板点重试。
- App ID 和 App Secret 加密保存在本机，启动时作为环境变量传给程序。
- AI 用这个应用的身份读写内容，能动哪些内容取决于应用申请的权限，只给需要的。
- 只在本机会话里生效。
- 不想用了：在发现页点「停用」。
