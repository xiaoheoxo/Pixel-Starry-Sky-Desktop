# Canva 连接器

让 AI 用你的账号搜索、生成和导出 Canva 设计。

## 怎么用

1. 在 设置 › 扩展 › 发现 点「连接」。
2. 新开一个对话，发第一条消息。
3. 在提示条或右侧「连接器」面板里点「登录」，到浏览器里授权。
4. 接着说就行，AI 会自己选工具。

## 要知道的

- 连接地址：`https://mcp.canva.com/mcp`，服务由 Canva 提供，扩展里没有程序。
- AI 用你登录的账号读取和修改内容；要不要先问你，由会话的权限模式决定。
- 登录记录由引擎保存，Claude Code、Codex、像素星空引擎第一次用时要各登录一次。
- 只在本机会话里生效。
- 不想用了：在发现页点「停用」。账号授权要到 Canva 那边撤销。
