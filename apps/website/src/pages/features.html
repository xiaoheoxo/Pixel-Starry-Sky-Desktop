01任务看板

多个任务同时跑，一张看板全掌握

每个会话独立运行，侧栏和看板显示谁在跑、谁在等你、谁出错了。

  • 等你审批的命令直接在看板上允许或拒绝
  • 出错的任务一键重试，不用翻回对话
  • 完成时系统通知，切走也不会错过
02模型菜单

一个菜单换模型、换线路

Claude Code、Codex、像素星空三种引擎，模型菜单里随时切换，对话接着聊。

  • 用像素星空余额、自己的订阅或自定义接口
  • 额度、上下文用量在输入框下面实时显示
  • 换引擎时自动交接之前的对话
03账号多开

多个订阅账号，点一下就换

Claude 和 ChatGPT 都能登录多个账号，各自的 5 小时、本周额度一目了然。

  • 切换不用重新登录，对话记录、插件、MCP 共用
  • 额度用完可以自动换到下一个账号（默认关闭）
  • 登录凭据由命令行自己保存，像素星空不读取
04代码页

代码、Git、终端，都在旁边

代码页把文件树、编辑器、AI 的改动、终端和对话放在一起。

  • 「AI 这一轮改的」单独列出，逐个审查
  • Git 改动、历史、分支，不用切到别的软件
  • AI 跑的命令能在终端里接着看
05扩展中心

主题、技能、插件，装好就能用

语法高亮、主题、代码片段、技能、提示词，装好立刻生效；插件和 MCP 连接器统一管理。

  • 商店里的扩展都经过审核
  • Claude Code / Codex 原有的插件和 MCP 照样能用
